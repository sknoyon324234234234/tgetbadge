# Code of Conduct

## Our pledge

Everyone is welcome here. We want participation in this project to be a
harassment-free experience for everyone, regardless of background or
experience level.

## Expected behavior

- Be respectful and kind
- Give and accept constructive feedback gracefully
- Focus on what is best for the project and its community

## Unacceptable behavior

- Insults, harassment or personal attacks
- Publishing other people's private information
- Any other conduct that would be inappropriate in a professional setting

## Enforcement

Report problems to the repository owner. All reports will be reviewed and
handled confidentially.
